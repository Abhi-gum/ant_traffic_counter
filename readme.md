### Project Description
### 🐜 Ant Traffic Counter

An AI-powered computer vision system that detects and tracks ants in video using YOLO.
It automatically counts unique ants crossing a defined line, providing an efficient real-time traffic count from video footage.


### The Problem (that doesn't exist)
Manually counting ants in a video is difficult and time-consuming, especially when many ants move at the same time. There is a need for an automated system to accurately detect and count ants passing through a specific point.


### The Solution (that nobody asked for)

We use **YOLO-based computer vision** to detect ants in the video and track them as they move. A counting line is used to automatically count each ant when it crosses the line.

#### **# Installation**

Install Python dependencies using:

```bash
pip install ultralytics opencv-python numpy flask
```

For the frontend, no separate installation is required since it uses HTML, CSS, and JavaScript.

#### **# Run**

Run the ant detection and counting program using:

```bash
python count_ants.py
```

To run the web interface:

```bash
python app.py
```

Then open the displayed local URL in a web browser.

## **### Project Documentation**

The **Ant Traffic Counter** is a computer-vision-based system designed to automatically detect, track, and count ants in a video. It uses a **YOLO model** for ant detection and **object tracking with a counting line** to count each ant only once.

The system takes a video as input, processes each frame, detects ants, tracks their movement, and displays the total number of ants crossing the designated counting area.
